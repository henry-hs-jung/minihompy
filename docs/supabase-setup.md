# Supabase 연결 진행

## 관리자 로그인 연결

사용자가 초기 SQL 적용과 관리자 UUID 등록을 완료했다고 확인했다. 초기 SQL 적용 후 실제 비로그인 RPC 응답 `false`를 확인했다. 관리자 UUID 등록 여부는 공개 API로 조회하지 않으며 실제 로그인으로 확인해야 한다.

상단 로그인 버튼에 `admin-auth.js`와 작은 이메일/비밀번호 모달을 연결했다. SDK 로그인 성공 후 `getUser()`와 관리자 판정 RPC까지 성공해야 `MinihompyAdmin.state.role`이 `admin`이 된다. 로그인 성공 시 버튼은 로그아웃으로 바뀐다. 작성·수정 버튼은 아직 비활성이다.

관리자 로그아웃은 `scope: 'local'`로 처리하고 방문자용 클라이언트/저장소는 건드리지 않는다. 비밀번호는 로그인 시도와 창 닫기 후 입력란에서 지운다. 저장된 관리자 세션은 새로고침 시 서버 확인을 거쳐 복원하며, 확인 실패 시 관리 UI 권한을 부여하지 않는다. 클라이언트 상태는 보안 경계가 아니며 콘텐츠 RLS 검증은 여전히 필요하다.

`scripts/verify-admin.mjs`는 모의 Auth 응답으로 데스크톱/모바일, 로그인 오류, 비관리자 거부, 네트워크 실패, 관리자 승인, 로그아웃, 비밀번호 제거, Escape를 검사했다. 실제 관리자 자격 증명은 수집하지 않았고 실제 계정 로그인은 사용자가 브라우저에서 확인해야 한다.

상단의 기존 정적 로그아웃 문구가 이제 로그인 상태에 따라 달라지는 것은 의도한 변경이다. 메뉴 회귀 검사의 과거 HOME 픽셀 비교는 이 한 요소만 원래 문구로 복원한 뒤 수행한다. 그 외 기준 화면 픽셀과 15개 탐색 시나리오는 통과했다.

아래는 최초 연결 당시의 설정 기록이며, SQL 적용/계정 등록 안내는 완료된 단계다.

## 완료

- 프로젝트: `itkymmxnbjylyzbmdxdb`.
- 공개 URL과 publishable key를 `supabase-config.js`에 저장. 공개용 키이며 DB 관리 권한을 부여하지 않는다.
- SDK 2.116.0을 로컬에 고정하고 라이선스와 다운로드 검증 스크립트를 포함했다.
- `MinihompyBackend.getClient('visitor' | 'admin')`으로 지연 생성. 관리자/방문자 세션 저장소를 분리했다. URL 세션 자동 감지는 비활성이다. 이후 이메일/비밀번호 로그인은 별도 UI에서 연결한다.
- 실제 공개 Auth 설정 조회 성공. 익명 인증은 비활성 상태였다.
- 관리자 확인 RPC 호출 결과 PGRST202: 함수가 아직 API 스키마에 없다.

이번 확인은 설정 조회와 읽기 전용 RPC 호출뿐이다. 사용자 생성·로그인·테이블 변경·SQL 적용은 수행하지 않았다. SDK를 추가해도 읽기 화면은 네트워크에 의존하지 않는다.

## 다음 사용자 작업: SQL 적용

1. 해당 프로젝트의 SQL Editor에서 새 쿼리를 연다.
2. `supabase/migrations/202609130001_identity.sql`의 전체 내용을 실행한다. 새 프로젝트에 한 번 적용하는 마이그레이션이다.
3. 성공 여부를 알려준다. 이후 공개 API에서 `is_minihompy_admin()`이 비로그인 요청에 `false`를 반환하는지 확인할 수 있다.

이 SQL은 관리자 목록과 판정 함수만 만든다. 아직 관리자를 등록하거나 방문자 작성을 허용하지 않는다. 공개 키로 SQL을 실행할 수 없으므로 프로젝트 소유자가 대시보드에서 실행해야 한다. 이를 위해 secret/service_role 키를 공유할 필요는 없다.

## 그다음

관리자 Auth 사용자 생성과 UUID 등록 → 익명 인증/CAPTCHA 설정 → 콘텐츠 테이블 및 RLS → 로그인·작성 화면 연결 순서다. CAPTCHA와 작성 제한이 준비되기 전에는 익명 작성을 공개하지 않는다.

공식 참고: [클라이언트 초기화](https://supabase.com/docs/reference/javascript/initializing), [익명 인증](https://supabase.com/docs/guides/auth/auth-anonymous).
