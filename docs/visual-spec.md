# HOME Visual Spec v2

작업 6의 현재 적용값은 아래 보정 기록과 JSON을 따른다. 이후 본문의 초기 관측 표는 계측 이력으로 보존하며, 관측 이미지의 사각형과 실제 CSS 윤곽을 구분한다.

## 작업 6 보정

- 패널 높이 241 → 240px, 펼침면 높이 265 → 264px, 점선 경로 높이 274 → 272px. 원래 관측 허용치(주요 영역 ±2px, 점선 ±3px)를 유지하며 하단 수평선의 겹침을 개선했다. 원본 측정 JSON은 수정하지 않았다.
- 안쪽 보조 윤곽을 점선 바깥에서 안쪽으로 이동했다. 펼침면은 `#f1f1f0`, 격자 선은 `#9f9f9f`, 점선 불투명도는 0.7이다. 외곽 크기와 바인더 축은 유지한다.
- 최근게시물 제목 구분선은 왼쪽 열까지만 표시한다. 통계 시작은 x=290,350이며 안내문은 2px 내렸다. 프로필 하단 선택 상자는 2px 내리고 제목은 1px 내렸다.
- 본문은 별도 `Minihompy Home` 대체 폰트를 사용한다. 안내문·말풍선·일촌평 6px, 상단 메뉴·미니룸 보기·우측 보조 영역 6.5px, 통계 라벨 6.5px, 구역 제목 7px, 페이지 제목 8px이다. 행간은 CSS/JSON의 역할별 값이며 자간 0을 유지한다.
- 탭의 6px / scaleX(.92) 설정과 폰트 파일은 변경하지 않았다. 본문을 일괄 확대하지 않고 역할별 후보를 비교했다.

[작업 6 검증](verification/step6/README.md)에 50% 겹침, 픽셀 차이, 변경 전후 영역별 수치와 남은 한계를 기록했다. 아래에서 '작업 5에서 결정' 등으로 표시된 문장은 초기 계획 이력이다.

작업 3에서 확정한 첫 구현 기준이다. [master](../references/cyworld-master.png)의 정적 HOME 화면을 복원하며, 글 작성·로그인·Supabase·방명록 동작·배포는 범위 밖이다.

## 기준과 확정의 의미

우선순위는 master → [동일 화면의 R06 사본](../references/research/moneytoday-master-related.jpg) → [조사 보고서](reference-research.md)의 제한적 보조 자료 순서다. 원본의 비율·배치·콘텐츠 상태를 우선한다. `미니라이프`도 master에 있으므로 표시한다. 이는 엄밀한 2008년 이전 화면을 보증하는 작업이 아니라 주어진 화면의 복원이다. 연도에 관한 상충 근거는 조사 보고서에 남겨 두었다.

아래 숫자는 첫 구현에서 사용할 값이다. `관측`은 이미지 계측, `선택`은 구현을 위한 결정, `잠정`은 작업 6에서 시각 비교로 보정할 값이다. 원래 서비스의 CSS나 폰트를 복구했다고 주장하지 않는다.

- 좌표 원본: [master-measurements.json](measurements/master-measurements.json). 기존 관측값을 유지한다.
- 구현 토큰: [visual-spec.json](visual-spec.json). 크기·색상·글자 역할·표시 상태·검증 조건을 기록한다.
- 자산 목록: [asset-inventory.md](asset-inventory.md). 확보된 참고 이미지와 아직 필요한 자산을 구분한다.

## 전체 배치

좌표는 전부 캔버스 기준 `(x, y, width, height)`다. 부모 기준 CSS 좌표를 사용할 때는 부모의 원점을 빼며, 부모 테두리에 따른 1px 이동도 고려한다. 반올림 오차를 막기 위해 첫 구현은 전체 기준 좌표와 `getBoundingClientRect()` 결과를 대응시킨다.

| ID | 영역 | 기준 사각형 |
| --- | --- | --- |
| A01 | 상단 사이트 메뉴 | 7, 4, 560, 16 |
| A02 | 회색 격자 배경 | 7, 20, 560, 323 |
| A03 | 하늘색 외곽 프레임 | 19, 32, 435, 293 |
| A04 | 점선 둘레 | 29, 42, 414, 274 |
| A05 | 밝은 펼침면 | 33, 46, 405, 265 |
| A06 | 좌측 프로필 패널 | 36, 68, 112, 241 |
| A07 | HOME 패널 | 150, 68, 279, 241 |
| A08 | 우측 탭 묶음 | 432, 73, 31, 161 |
| A09 | 우측 부가 영역 | 469, 32, 92, 158 |

프레임 아래에 별도 상태바·뉴스 티커를 추가하지 않는다. 왼쪽 패널과 오른쪽 패널 사이의 약 2px 간격, 왼쪽보다 넓은 프레임 우측 여백, 제목과 본문이 서로 다른 x에서 시작하는 배치를 보존한다.

## 프레임과 바인더

쌓이는 순서는 배경(0) → 외곽 프레임(10) → 점선(11) → 펼침면(12) → 패널(20) → 콘텐츠(30) → 스크롤바(35) → 탭(40) → 고리(50)다. 우측 부가 영역과 상단 메뉴는 프레임 밖에 놓인 독립 영역이다.

- 격자는 9px 간격, 선 두께 1px로 시작한다. x=7, y=20을 패턴 원점으로 쓰면 관측된 어두운 선 x=484,493,502 및 y=228,237,246과 대응한다. CSS 반복 배경으로 만든다.
- 외곽은 하늘색, 밝은 안쪽 띠와 점선, 회백색 펼침면, 흰 패널의 순서다. 안쪽 윤곽은 바인더 축 x≈149 부근의 굴곡을 포함한다.
- 최초 윤곽은 반경 7px, 패널 반경 6px, 테두리 1px로 시작한다. 중앙 굴곡은 축 좌우 약 8px 구간에 깊이 약 2px를 주는 잠정 형태로 정의한다. 상단은 아래로 패이고 하단은 대응하는 펼침면 이음 모양을 만든다. R06과 비교해 보정한다.
- 굴곡과 점선의 연속성을 위해 코드로 만든 SVG path를 프레임에만 사용할 수 있다. 직선 패널과 탭은 CSS로 만든다. 좌우 책장을 각각 큰 라운드 박스로 처리해서 중앙에 틈이 생기지 않게 한다.
- 점선은 1px 선, 2px 대시 / 2px 간격으로 시작한다. 경계를 따라 이어지며 패널 내부를 가로지르지 않는다.
- 네 고리의 외접 사각형은 `(143,105,12,7)`, `(143,122,12,7)`, `(143,250,12,7)`, `(143,267,12,7)`이다. 회색 윤곽, 밝은 내부, 가는 하단 음영의 납작한 고리다. 단순 문자나 체인 아이콘으로 대체하지 않는다.
- 프레임에 큰 확산 그림자를 넣지 않는다. 필요한 입체감은 1px 안팎의 윤곽·밝은 선으로 표현한다.

## 탭과 스크롤바

탭 너비는 31px이며 x=432를 유지한다. y 경계는 `73, 90, 108, 126, 144, 162, 180, 198, 216, 234`다. 첫 탭은 17px, 나머지는 18px 높이다. 라벨 순서는 `홈, 프로필, 다이어리, 쥬크박스, 사진첩, 갤러리, 게시판, 동영상, 방명록`이다.

`홈`만 밝은 배경에 짙은 글씨, 나머지는 청록 바탕에 밝은 글씨다. 오른쪽 모서리 반경은 잠정 3px다. 탭은 외곽 프레임 밖으로 약 9px 돌출되며, 선택 탭의 왼쪽이 펼침면에 붙어 보이도록 경계를 처리한다. 탭 묶음을 overflow로 잘라내지 않는다. hover·focus가 탭 크기나 위치를 바꾸면 안 된다.

HOME 스크롤바는 B15 `(417,74,9,225)`의 시각 요소다. 상하 화살표와 밝은 회색 트랙을 해당 위치에 재현한다. 정적 HOME에는 실제로 넘치는 콘텐츠가 없으므로 이 단계에서는 장식으로 두고 스크롤 동작을 가장하지 않는다. 이후 실제 콘텐츠 스크롤을 만들 때 별도 구현한다. 운영체제 기본 스크롤바의 폭·색상에 의존하지 않는다.

## 글꼴과 글자 크기

작업 4 후 [탭 글자 재검토](tab-typography.md)에서 7px 탭의 가시 폭이 원본보다 넓음을 확인했다. 탭에만 로컬 Galmuri11 서브셋을 적용하고 6px, 가로 배율 0.92로 보정했다. 이는 확인된 원본 폰트가 아닌 대체 자산이며 본문에는 적용하지 않는다.

첫 CSS 글꼴 스택은 `Dotum, '돋움', Gulim, '굴림', sans-serif`, 영문 카운터는 `Arial, sans-serif`로 정한다. 원본 글꼴로 확인된 값이 아니라 비교를 시작하기 위한 선택이다. 모든 `letter-spacing`은 0이다.

| 역할 | CSS font-size | line-height | weight |
| --- | ---: | ---: | ---: |
| 본문·안내문 | 7px | 10px | 400 |
| 탭 (별도 웹폰트, 가로 배율 0.92) | 6px | 9px | 400 |
| 상단 메뉴·보조 링크 | 6px | 8px | 400 |
| 방문자 카운터 | 5px | 8px | 400 |
| 섹션 제목 | 8px | 10px | 700 |
| 미니홈피 제목 | 9px | 11px | 700 |

글리프 가시 높이와 line box는 다르다. 계측 사각형 B01~B19는 보이는 요소의 범위이며 그대로 line-height로 쓰지 않는다. 텍스트의 가시 상단·폭을 비교하며 baseline을 조정한다. 작은 글씨를 읽기 좋게 키우거나 임의의 음수 자간으로 폭을 맞추지 않는다.

현재 Linux 환경의 한글 지원 폰트 목록에는 WenQuanYi와 Unifont 계열이 있고, 돋움·굴림은 없다. 실제 적용 폰트가 대체된 상태에서는 글꼴 복원 완료로 판정하지 않는다. 작업 5에서 한글 글리프 비교와 재현 가능한 폰트 제공 방식을 결정하고, 확보 전까지는 시스템 대체 글꼴임을 검증 기록에 남긴다. 폰트 파일을 확보한 것으로 가정하거나 전체 UI 글자를 이미지로 바꾸지 않는다.

## 정적 HOME 내용

텍스트와 조작부는 HTML로 작성하고, 프로필 그림·미니미·배너만 래스터 자산으로 취급한다. 화면 전체나 패널 전체를 캡처 이미지로 덮어씌우지 않는다.

| 요소 | 배치와 표시 상태 |
| --- | --- |
| 방문자 수 | B01, TODAY 1 / TOTAL 2. 좁은 영문 카운터 유지 |
| 제목 | B02의 가시 기준 x≈181, y≈56. master의 짧은 제목 길이 유지 |
| 제목 오른쪽 링크 | B03, 일촌맺기 / 팬되기, 주황색 |
| 프로필 | B04의 기존 그림과 B05의 자기소개 없음 문구. 중간 빈 공간 유지 |
| 프로필 하단 | B06, HISTORY·이름 영역·파도타기 선택 상자. 바닥까지 늘리지 않음 |
| 최근게시물 | B07 제목. B08 왼쪽은 빈 상태 안내, 오른쪽은 2열 × 3행의 게시판 수 |
| 게시판 수 순서 | 다이어리 / 사진첩, 갤러리 / 게시판, 동영상 / 방명록. 0/0 표기, 방명록만 0/1 |
| 미니룸 보기 | B09, 미니라이프 / 미니룸 / 스토리룸. 미니룸만 강조 |
| 미니룸 | B10의 240 × 75px 흰 공간, B11 말풍선, B12 미니미. 가구·방 배경 없음 |
| 말풍선 | 미니룸 준비중. 회색 얇은 윤곽, 흰 바탕, 아래 오른쪽 꼬리 |
| 일촌평 | B13 회색 띠와 제목, B14 주황 원형 아이콘·안내문·우측 일촌신청 |

내용 기준선은 x=168, 오른쪽은 x=408이다. 최근게시물의 열 구획은 x≈287과 x≈350을 잠정 기준으로 삼고 행은 약 14px 간격이다. 미니룸 아래 5px를 띄워 y=222에 하단 제목 띠를 놓는다. 말풍선과 미니미는 서로 약간 겹치는 원본 관계를 유지한다.

작은 문구의 정확한 판독이 어려운 곳은 R06을 확대해 확인한다. 그래도 읽히지 않는 짧은 이름·광고 문구는 미확정으로 기록하고, 긴 새 문장을 만들어 채우지 않는다. 현재 단계에서 개인 홈페이지 이름이나 프로필을 새로 디자인하지 않는다.

## 상단·우측 부가 영역

상단 A01은 낮은 한 줄이다. 왼쪽 검색 필드와 빨간 검색 버튼, 오른쪽 작은 메뉴와 얇은 구분선을 둔다. 첫 위치 추정은 검색 필드 `(19,6,70,12)`, 버튼 `(89,6,21,12)`이다. 상단 메뉴의 시작은 x≈247로 잡는다. 이 세부 좌표는 추가 관측에 따른 잠정값이다.

A09의 흰 영역 안에서 위부터 친구추천·작은 이름/관계 표시, 댓글·스크랩·소망상자, 액티브 막대, 음악 조작부, 선물가게/추천BGM, 두 개의 작은 배너가 이어진다. 최근 서비스의 카드·큰 아이콘으로 대체하지 않는다.

| 우측 구획 | master 기준 잠정 사각형 |
| --- | --- |
| 추천·관계·통계 | 474, 35, 82, 67 |
| 음악 조작부 | 474, 109, 82, 21 |
| 선물가게 / 추천BGM 제목줄 | 475, 135, 80, 10 |

선물 배너 등 기존 이미지의 범위는 자산 목록에서 참조한다. 광고·추천 링크는 외부 사이트로 연결하지 않는다. 정적 조작부는 포커스나 입력이 필요한 요소와 장식 요소를 구분하고, 눌렀을 때 로그인 창이나 준비중 팝업을 띄우지 않는다. 구현 설명 문구를 화면에 추가하지 않는다.

## 구현과 검증 순서

작업 4에서는 캔버스·격자·상단·프레임·점선·패널·고리·탭·스크롤바·우측 영역의 골격까지 만든다. 작업 5에서 텍스트와 래스터 자산을 넣는다. 구현은 HTML/CSS/JS 정적 파일을 기본으로 하며 이 화면만을 위해 프레임워크나 빌드 도구를 도입하지 않는다.

작업 6의 기준은 다음과 같다.

1. 579 × 349, DPR 1에서 찍은 결과를 master와 동일 크기로 비교한다. 이미지와 폰트가 로드된 뒤 캡처하며 사용한 브라우저·폰트를 기록한다.
2. 주요 A 영역의 위치·크기 오차는 관측 허용치 ±2px 이내, 점선은 ±3px 이내에서 시작한다. 큰 틀을 맞춘 뒤 선명한 직선 경계는 가능한 1px 이내로 줄인다.
3. 네 고리, 아홉 탭, HOME 선택 상태, 빈 미니룸, 우측 두 배너, 하단 빈 공간을 확인한다. 바깥 프레임과 탭이 잘리면 실패다.
4. 픽셀 차이와 50% 겹침 이미지를 참고하되 흐림·압축·폰트 차이가 있으므로 전체 유사도 점수 하나로 합격시키지 않는다.
5. 1280 × 800에서도 캔버스 좌표와 크기가 같다. 375 × 812에서는 캔버스가 축소되지 않고 가로 스크롤로 오른쪽 끝까지 볼 수 있어야 한다.
6. 글자가 서로 겹치거나 영역을 밀어내지 않아야 한다. 키보드 포커스가 있는 요소는 윤곽이 보이되 치수를 바꾸지 않는다.

## 남은 한계

미확정 사항은 원래 폰트·CSS 해상도·스킨 상품명, 원본 개별 이미지 파일, 흐린 일부 문구다. v1은 작업을 시작할 수 있는 구현 기준을 확정한 것이며 이런 역사적 사실을 확정한 것은 아니다. 글꼴·래스터 자산이 대체 상태라면 최종 검수에서 그 차이를 반드시 남긴다.
