# 게시판 시각 구현

후속 단계에서 실제 DB 읽기와 관리자 작성/수정/삭제를 연결했다. 현재 동작은 [게시판 작성 연결](board-writing.md)을 참고한다. 아래는 시각 구현 당시 기록이다.

## 확정 범위

사용자 결정: 넓게 보기 미지원. B03처럼 좌측 폴더와 우측 본문을 분리하며, 본문은 페이지 단위 목록에서 글 상세로 전환한다. 사진첩처럼 상세 글을 나열하지 않는다.

외곽은 기존 master 프레임을 그대로 유지했다. B01/B02의 내부 요소를 일반 폭으로 재배치한 구현이며, 미확보된 일반형 원본의 픽셀 복제라고 주장하지 않는다. 조사 기록은 [게시판 자료 조사](board-reference-research.md)를 참고한다.

## 파일과 데이터

- `board-data.js`: 폴더, 구분선, `pageSize`, 공개 샘플 글.
- `views/board.js`: 좌측 탐색, 목록, 페이지 이동, 상세, 목록 복귀.
- `styles.css`: `board-` 범위 스타일. 폴더 아이콘만 기존 사진첩 표현을 재사용한다.
- `index.html`: 데이터와 화면 스크립트 등록.

폴더는 평면 배열이다. 일반 항목은 고유한 `id`, `label`, `description`, 구분선은 `{ type: 'divider' }`를 사용한다. `__all__`은 전체보기용 예약 ID다. 글의 `folder`는 폴더 ID를 가리킨다. 글 ID도 고유해야 한다.

글은 `id`, `folder`, `title`, `body`, `author`, `date`, `views`로 구성한다. `author: null`이면 `config.profile.name`을 사용한다. 날짜 형식은 `YYYY.MM.DD HH:mm`. 본문은 줄바꿈을 보존하는 일반 문자열이며 HTML로 해석하지 않는다. 샘플 날짜는 창작 데이터이지 캡처 시점의 근거가 아니다.

## 동작

- 최초 진입은 전체보기, 한 페이지 10개. 데이터 배열 순서대로 표시한다.
- 폴더 변경은 목록 1페이지로 이동한다.
- 제목 클릭은 좌측 폴더를 유지한 채 상세로 전환한다.
- 목록 버튼은 원래 폴더·페이지·목록 스크롤로 복귀하고 해당 제목에 포커스를 돌려준다.
- 다른 우측 메뉴를 다녀와도 선택 폴더·페이지·상세 글을 메모리에 유지한다. 새로고침은 초기화한다.
- 페이지 번호는 10개씩 묶는다. 빈 폴더와 긴 제목/본문을 처리한다.
- 내부 스크롤은 얇은 네이티브 스크롤이다. 모바일은 기존 고정폭 가로 스크롤 정책을 따른다.

## 제외 사항

작성·저장·로그인·권한·비밀글·넓게 보기 없음. 글쓰기·폴더관리·작업 링크·댓글 입력은 비활성이다. 등록된 댓글 목록은 자료 미확보로 만들지 않았다. 관리자 일괄 선택 UI, 태그 편집, 실제 스크랩 수 등의 기능도 이번 범위에서 제외했다. 스크린샷의 타인 이름·본문·스킨은 앱에 복사하지 않았다.
