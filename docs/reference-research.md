# 미니홈피 복원 참고 자료 조사

조사일: 2026-09-13. 작업 2의 결과이며 구현 명세 확정이나 HOME 개발은 포함하지 않는다.

## 핵심 결과

**master와 같은 화면 내용을 담은 740 × 448px JPEG를 확보했다.** 2015-09-30 머니투데이 기사에 실린 옛 화면으로, 프로필 그림·방문자 수·빈 미니룸·배너까지 대응한다. 가장 가까운 보조 자료는 이 이미지 R06이다. 다만 기사는 최초 캡처 날짜를 밝히지 않는다. [R06 출처](https://www.mt.co.kr/society/2015/09/30/2015093013531661158)

**master를 2008년 이전 화면이라고 확정할 수 없다.** 이미지에서 판독되는 `미니라이프`는 운영사 자료상 2008-07-08 정식 출시되었으며, 같은 자료는 그해 5월 말 비공개 시범서비스도 언급한다. 정상 서비스 캡처라는 전제에서 2008년 이후일 가능성이 높다. 이것은 메뉴 표기와 출시 기록을 연결한 추론이며, master의 촬영 연도를 확정한 것은 아니다. [운영사 미니라이프 발표](https://www.newswire.co.kr/newsRead.php?no=346316)

한편 2006년 자료 사진에서도 회색 격자·하늘색 점선 프레임·네 개의 고리·오른쪽 탭이 확인된다. 따라서 오래된 프레임 형태와 나중에 추가된 메뉴가 같은 화면에 공존할 수 있다. 사진의 연도는 해당 언론사의 캡션에 근거한다. [R04 출처](https://www.koreatimes.co.kr/business/tech-science/20191013/cyworld-faces-business-shutdown)

이번 조사에서는 master 우선순위를 유지한다. 연도에 맞춘다는 이유로 master의 메뉴를 삭제하거나 다른 HOME 구성으로 바꾸지 않는다. **엄밀한 2008년 이전 복원과 master 전체 재현 사이에는 충돌 가능성이 있음**을 작업 3에 넘긴다. 아직 화면이나 기존 계측값을 변경하지 않았다.

## 자료 판별 방식

- 게시일, 실제 캡처일, 화면 안에 쓰인 날짜를 서로 구분했다.
- 검색 결과의 자동 이미지 설명은 탐색에만 사용했다. 아래 시각 비교는 다운로드한 이미지를 직접 확인한 결과다.
- 기본 프레임의 형태와 HOME 내용 배치가 모두 맞는지 확인했다. 하늘색이라는 이유만으로 같은 테마로 분류하지 않았다.
- 보도자료는 기능 도입 시기와 의미를 확인하는 데 사용했다. 글꼴이나 CSS 수치는 원본 코드가 없으면 확정하지 않았다.
- 후대 재게시 이미지는 세부 확인용으로만 사용하고 그 게시 연도를 캡처 연도로 옮겨 적지 않았다.

### R06: master와 같은 내용의 재게시 화면

[기사](https://www.mt.co.kr/society/2015/09/30/2015093013531661158) · [JPEG](../references/research/moneytoday-master-related.jpg)

740px 너비를 master의 유효 화면 너비 560px로 줄이면 배율은 약 0.7568이다. 좌측 7px·상단 약 4px 여백을 더하는 대응을 가정하면, R06 프레임의 대략적인 `(16,37)` 위치는 master의 `(19,32)`와 맞는다. 주요 영역과 그림 배치도 대응한다. **동일한 화면의 크기가 다른 사본으로 보인다는 시각적 추론**이며 파일 생성 경로나 픽셀 단위 동일성은 검증하지 않았다. 740px가 원래 브라우저의 CSS 너비라는 뜻도 아니다.

### R04: 2006년 실제 사용 사진

[기사와 연도 캡션](https://www.koreatimes.co.kr/business/tech-science/20191013/cyworld-faces-business-shutdown) · [사진](../references/research/koreatimes-2006-photo.jpg)

IE 창 안에서 별도의 미니홈피 창이 열린 모습이다. 격자 배경, 하늘색 프레임, 밝은 점선, 펼침면의 중앙 굴곡, 두 쌍의 고리, 우측 탭과 부가 영역이 보인다. HOME에는 최근 소식·꾸며진 미니룸·하단 일촌평이 배치되어 있다.

프레임 계열은 가깝지만 실제 모니터를 비스듬히 촬영해 원근 왜곡과 화면 반사가 있다. 색상 채집, 절대 치수, 폰트 식별의 기준으로는 쓰지 않는다. 탭 수, 미니룸의 높이, 오른쪽 지수 표시를 master에 이식하지 않는다.

### R03: 2005년 문화관광부 미니홈피

[기관 보도자료](https://www.newswire.co.kr/newsRead.php?no=73393) · [화면](../references/research/ministry-2005.jpg)

당시 운영 기관이 제공한 화면이라 시기 근거가 강하다. 좌측 프로필, 중앙 HOME, 바인더, 우측 탭·보조 영역의 기본 구조를 확인할 수 있다. 하지만 브랜드 배경과 콘텐츠가 다르고 제공된 480px 이미지가 흐려서 색상·치수·글꼴에는 적용하지 않는다.

### R01·R02: 같은 시리즈의 다른 스킨

[재게시 글](https://briskeen.com/770) · [R01](../references/research/briskeen-blue-frame.jpg) · [R02](../references/research/briskeen-blue-room.jpg)

R01은 파란 바탕이지만 master의 하늘색 외곽 프레임과 격자·점선이 없다. 빈 미니룸과 고리 형태만 참고한다. R02는 회색 바탕에 좌측 패널과 바인더 표현이 생략된 스킨이다. 둘 다 영문 섹션 제목·탭, Review 구성이 있어 HOME 배치 기준에서 제외한다. 게시일만으로 옛 캡처 시기를 정할 수 없다.

### R05: 미니서치 홍보 이미지

[운영사 보도자료](https://www.newswire.co.kr/newsRead.php?no=318372) · [홍보 이미지](../references/research/minisearch-2008.jpg)

## 글꼴·자산 조사 결과

기본 UI 글꼴의 이름과 정확한 CSS `font-size`는 확보한 자료로 확정하지 못했다. R06은 작은 문구의 판독을 개선하지만 브라우저의 원래 글꼴 선언을 제공하지 않는다. 돋움 등 시스템 글꼴은 이후 비교 실험 후보일 뿐, 이 조사에서 확인된 원본 글꼴이 아니다.

싸이월드에는 별도 글꼴 상품이 있었고, 운영사 자료는 2005년 8월 글꼴 서비스 도입을 명시한다. 따라서 다른 사람의 캡처에서 보이는 글씨체가 기본 UI 글꼴과 같다고 가정해서는 안 된다. [운영사 글꼴·음악 연동 발표](https://www.newswire.co.kr/newsRead.php?no=334593)

이번에 확보한 것은 화면 사진과 캡처다. 원래 서비스의 CSS, 프레임용 이미지 조각, 투명 미니미 GIF, 프로필 원본 자산, 폰트 파일은 확보하지 못했다. 자료 이미지는 비교용으로 저장했으며 제품 자산으로 편입하거나 잘라내지 않았다.

## 작업 3에 넘길 사항

1. 계측 기준은 기존 `cyworld-master.png`와 작업 1 좌표를 유지한다. R06으로 문구·테두리 세부를 보완한다.
2. 시각 자료 우선순위는 master → R06 → R04의 구조 확인 순서다. R03은 시대별 구조 비교, R01·R02·R05는 제한적 보조 자료다.
3. 원래 캡처 해상도·CSS 배율·기본 글꼴·정확한 스킨 상품명은 미확정이다. 프레임의 외형이 같다는 것과 같은 상품임을 입증하는 것은 구분한다.
4. 2008년 이전이라는 연도 조건과 `미니라이프`가 포함된 master의 충돌을 명세에 명시해야 한다. 현재는 master 재현을 우선하는 해석으로 조사 결과를 정리했다.
5. 자료 6개의 다운로드와 디코딩을 확인했고, 모든 이미지를 직접 열어 비교했다. 데이터베이스·로그인·HOME 구현은 시작하지 않았다.
