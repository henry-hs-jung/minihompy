# 시각 자산 목록

작업 5 갱신. 원본 서비스의 개별 GIF는 확보하지 못했으며 참고 화면의 네 그림 영역을 CSS로 표시한다. 아래 초기 작업 방침과 함께 실제 적용 결과를 기록한다.

## 래스터가 필요한 요소

좌표는 master 기준 가시 범위 또는 작업 3의 잠정 사각형이다. 이 영역이 원래 자산 파일의 전체 크기라는 뜻은 아니다.

| ID | 요소 | master 영역 | 확보 상태 | 작업 5 방침 |
| --- | --- | --- | --- | --- |
| I01 | 프로필 캐릭터와 원형 말풍선 | 56,80,76,72 (B04) | Master/R06 안에만 있음 | 같은 그림 부분을 재사용할 수 있는 출처 있는 이미지 조각으로 준비 |
| I02 | 미니룸의 작은 캐릭터 | 316,177,18,36 (B12) | Master/R06 안에만 있음 | 위치와 픽셀 외형 보존, 새 캐릭터로 대체하지 않음 |
| I03 | 왼쪽 작은 추천 배너 | 476,147,38,38 (잠정) | Master/R06 안에만 있음 | 해당 사각형의 실제 그림을 확인해 준비 |
| I04 | 오른쪽 작은 추천 배너 | 516,147,38,38 (잠정) | Master/R06 안에만 있음 | I03과 같은 방식 |

우선 경로는 기존 이미지의 제한된 영역을 활용하는 것이다. 작업 5에서 CSS background-position으로 원본 픽셀을 표시하거나 개별 조각을 추출하는 방식을 선택한다. 전체 master나 HOME 패널을 이미지 한 장으로 표시하지 않는다. 겹친 테두리·흰 바탕이 다른 영역을 덮지 않도록 실제 영역을 확인한다. 없는 세부를 생성형 이미지로 만들어 넣는 것은 이 복원의 기본 경로가 아니다.

R06 좌표로 옮길 때는 초기 대응식 `xR=(xM-7)×740/560`, `yR=(yM-4)×740/560`, `wR=wM×740/560`, `hR=hM×740/560`을 참고할 수 있다. 이는 후보 추출 위치 계산에만 사용하고, 실제 경계 확인 없이 확정하지 않는다. R06에 내재한 선명도·압축 차이 때문에 master 조각과 어느 쪽이 더 잘 맞는지는 시각 비교로 결정한다.

이미지 준비가 안 된 작업 4에서는 해당 자리를 빈 고정 영역으로 둔다. 완료된 작업 5·6에서 빈 영역이나 현대 일러스트를 원본 복원 완료로 보고하지 않는다.

## 작업 5 적용 결과

I01~I04는 위 표의 master 좌표 그대로 CSS background-position으로 표시한다. [cyworld-reference-sprite.png](../assets/cyworld-reference-sprite.png)는 사용자 제공 master의 수정 없는 사본이다. 파일 SHA-256은 `5a68654f3ac052afcc715995858155bb530d5ad2426d45ff52d27616e902b00c`. 크기는 579 × 349이며 실제 노출 영역은 네 그림뿐이다. 전체 화면·패널·본문을 이미지로 표시하지 않는다. 별도의 이미지 생성이나 픽셀 편집은 하지 않았다.

제목, 카운터, 프로필 상태와 하단, 최근게시물, 통계, 미니룸 선택 표시, 말풍선, 일촌평은 HTML/CSS로 구현했다. R06은 문구 판독에만 사용했다. 참고 화면 사용이 개별 그림의 재배포 권리 확보를 의미하지는 않으며 공개 배포 전 권리 확인이 필요하다.

## 자산 완료 기준

코드 요소는 명세의 좌표에 맞는지, 래스터 요소는 실제로 로드되는지·크기가 안정적인지·출처가 기록되는지 확인한다. 이미지를 대체하거나 재현한 경우 원본 확보와 구분해서 기록한다. 제품용 자산이 생기면 참고 자료 폴더와 구분된 `assets/`에 두되, 현재는 빈 자산 파일이나 경로만 만들어 두지 않는다.
