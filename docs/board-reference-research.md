## 화면에서 확인한 구조

- B01: 폴더 선택과 설명 → 공개 상태와 개수 → 선택란·번호·제목·작성자·작성일·조회 → 관리 버튼 → 페이지 번호.
- B01: 10행, 가로 구분선, 주황색 댓글 수와 선택 페이지. 세로 격자나 카드 없음.
- B02: 제목 → 작성자·시간·스크랩 수 → 본문 → 태그·공개 설정 → 작업 링크 → 회색 댓글 입력줄 → 글쓰기·목록.
- B03: 청록색 FREE BOARD, 전체보기, 폴더 아이콘. 그룹·폴더·구분선 추가와 방문자 게시물 등록 설정이 보임.

이 관찰의 근거는 위 원본 이미지다. 화면에 있는 관리자용 선택란·이동·삭제를 모든 방문자에게 보여야 한다는 뜻은 아니다.

## 시대와 폭을 구분해야 하는 이유

2008-04-16 개편에서 좌측 메뉴 공간을 사용하는 580px 게시판이 추가됐다. 기존 게시판은 최대 400px였다. [당시 보도](https://www.etnews.com/200804160004)

따라서 B01/B02를 **2008년 이전 일반형의 완전한 SoT로 확정할 수 없다.** 자료의 분홍 스킨, 좌측 영역을 합친 본문 폭도 채택하지 않는다.

## 복원 제안: 아직 확정 아님

1. 바깥 프레임·바인더·우측 탭은 `cyworld-master.png`를 유지한다.
2. 좌측 폴더는 B03을 보조 자료로 검토한다. 관리 화면 전체를 복제하지 않는다.
3. B01/B02는 목록과 상세의 **후보 자료**로 제시한다. 현재 일반 폭에 옮기면 재구성이라는 한계를 기록한다.
4. 일반형 원본을 확보하거나 사용자가 이 한계를 수용한 뒤 세부 치수를 확정한다.

이번에 고정할 수 있는 것은 화면 역할의 분리다: 폴더 선택 → 목록 → 글 상세 → 목록 복귀. 작성·저장·권한 기능은 기존 방침대로 나중에 다룬다.

## 미확인 사항

- 2008년 이전 일반 폭 목록/상세의 정확한 열 너비, 여백, 줄 높이.
- 등록된 댓글 행, 대댓글, 비밀글, 공지글, 첨부파일의 실제 표현.
- 방문자와 관리자 화면의 정확한 차이, 폴더 계층 제한.
- 원본 폰트 파일·CSS. 작은 비트맵형 글씨는 보이지만 굴림/돋움 등을 단정할 근거는 부족하다. 우측 탭의 자간·압축을 본문에 일괄 적용하지 않는다.

미확인 UI는 관습적인 게시판 디자인으로 채우지 않는다. B02의 댓글 입력줄만으로 댓글 목록 디자인을 확정하지 않는다.

## 추가 검색과 제외 기록

- 한국어 게시판 목록/작성일/조회, 영문 Cyworld free board, 2007년 스크린샷 및 2008년 넓게 보기 관련 검색을 수행했다.
- [2006년 연구 Figure 1](https://www.researchgate.net/figure/Sample-screenshot-of-Cyworld_fig1_45647758): 설명은 열람했으나 원본 이미지 요청이 403으로 실패했다. 게시판 화면으로 판정하지 않았다.
- [기존 다이어리·방명록 발표 자료](https://www.slideserve.com/mackensie-short/cyworld-boom-in-korea)의 slide27 이미지를 직접 확인했다. 댓글 기능에 관한 설명문뿐이므로 UI 기준에서 제외했다.
- 이미지 검색에 노출된 HOME·방명록, 현대 재현물, 타 서비스 게시판은 제외했다. 검색 엔진 이미지 설명만으로 메뉴를 판정하지 않았다.

## 재현 및 권리

`python scripts/fetch-board-references.py`로 원본 바이트를 보존하고 실제 파일 형식, 크기, SHA-256, 수집 시각을 기록한다. 자료는 연구용이며 배포용 자산으로 사용하지 않는다. 타인의 이름과 글은 앱 샘플 데이터에 복사하지 않는다.
