# 프로필 정적 구현

현재는 소개를 DB에서 조회하고 관리자가 편집한다. 아래 로컬 데이터/저장 미구현 설명은 초기 기록이며 [프로필 편집](profile-writing.md)으로 대체된다. 미확인 메뉴 공백과 원본 배치는 유지한다.

사용자 승인: PR01 SoT의 기본틀과 소개를 구현하고 미확인 메뉴 상세는 빈칸으로 유지한다.

- `views/profile.js`: 내 소개의 5개 메뉴와 내 인맥·내 즐겨찾기 묶음. 메뉴 전환과 접기/펼치기, 선택 표시 지원.
- 키워드·히스토리·42문답·기본정보·내 인맥·내 즐겨찾기는 본문 자식 요소가 없는 빈칸이다. 안내문, 가상 질문, 추정 하위 메뉴를 넣지 않았다.
- `profile-data.js`: 소개 이미지 URL, alt, 표시 폭, 이름, 문단 배열. 이름과 문단이 null이면 각각 config.profile.name과 config.profile.introduction을 사용한다. 빈 배열이면 소개 문단을 표시하지 않는다. 이미지를 빈 문자열로 지정하면 사진을 표시하지 않는다.
- 사진은 기존 `assets/photos/lake.jpg`를 임시 사용한다. 원본 인물 사진을 배포 자산으로 복사하지 않았다. 가로 192px, 세로는 이미지 비율을 유지한다.
- SoT 기준의 왼쪽 청록선, 작은 회색 아이콘, 상위 묶음, 들여쓴 하위 메뉴, 흰색 본문의 사진·이름·문단 배치. 아이콘과 폰트는 근사이며 원본 자산을 확보한 것은 아니다.
- 기존 579×349 캔버스와 외곽 프레임, 우측 탭을 유지한다. 본문은 필요할 때만 얇은 네이티브 스크롤바가 나타난다.
- 작성/저장 및 로그인은 추가하지 않았다. 세부 선택은 메뉴를 나갔다 돌아올 때 유지되지만 새로고침 시 소개로 초기화한다.

## 검증

`scripts/verify-profile.mjs`: 1000×700, 375×812 DPR 1·2. 소개 이미지 로딩, config 반영, 미확인 본문 완전 공백, 묶음 열기, 키보드 선택, 메뉴 재진입, 긴 글 스크롤, HTML 텍스트 처리, 리소스 오류 검사 통과.

`scripts/verify-navigation.mjs`: 15개 탐색 시나리오 및 기존 HOME 픽셀 동일성 통과.

이미지와 결과는 `docs/verification/profile-step2/`, `docs/verification/profile-navigation/`에 저장했다.
