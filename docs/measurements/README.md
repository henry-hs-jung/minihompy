# 기준 이미지 계측 기록

대상: `references/cyworld-master.png`  
범위: 작업 1. 이미지 자체의 계측만 수행. 웹 조사, 최종 visual spec 확정, HOME 구현은 아직 수행하지 않았다.

후속 기록: [작업 2 조사 결과](../reference-research.md)에서 같은 화면의 740 × 448px 사본과 시기 관련 단서를 확보했다. 아래는 작업 1 당시의 관측 기록으로 유지하며, 좌표값은 변경하지 않았다.

## 산출물과 좌표 규칙

- `master-measurements.json`: 영역 좌표와 색상 표본의 기계 판독용 원본.
- `cyworld-master-annotated.svg`: 원본을 변경 없이 내장한 계측도. 위쪽은 전체 구조, 아래쪽은 내부 요소이며 모두 2배로 표시한다. 좌표는 확대 전 원본 기준이다. 브라우저에서 사각형에 마우스를 올리면 ID와 치수를 확인할 수 있다.
- `../../scripts/render-measurements.mjs`: JSON을 검증하고 계측도를 다시 생성하는 스크립트. 저장소 루트에서 `node scripts/render-measurements.mjs`로 실행한다. 별도 패키지가 필요하지 않다.

원점은 이미지 좌측 상단 `(0, 0)`. 단위는 원본 이미지의 px. `(x, y, w, h)`는 좌상단과 너비·높이이며 오른쪽과 아래쪽 끝은 포함하지 않는다. 경계는 테두리를 포함한 가시 영역을 기준으로 한다. 둥근 모서리, 그림자, 곡선은 외접 사각형으로 기록했다. 이를 그대로 CSS의 content-box 치수로 해석하면 안 된다.

이미지 파일의 크기처럼 확정 가능한 값과 육안으로 경계를 지정한 값을 구분한다. 영역 경계의 기본 허용 오차는 약 ±2px이고, 점선 프레임은 ±3px이다. 이는 통계적 신뢰구간이 아니라 흐린 경계를 읽을 때의 실무상 추정 오차다. 투명 여백을 포함하는 원래 이미지 자산의 크기는 알 수 없다.

## 원본 상태

| 항목 | 확인 결과 |
| --- | --- |
| 파일 형식 | PNG, RGB, 채널당 8bit, 알파 채널 없음 |
| 이미지 크기 | 579 × 349px, 확정 |
| 종횡비 | 약 1.659 : 1 |
| PNG 부가 정보 | Pillow에서 읽히는 DPI·텍스트 등의 부가 정보 없음 |
| 바깥 여백 | 주요 화면이 x=7..566에 위치. 좌측 약 7px, 우측 약 12px, 아래 약 6px |
| 선명도 | 글자와 1px 경계 주위에 여러 중간색이 보이며 작은 한글 판독에 한계가 있음 |

축소 또는 재압축을 거친 화면일 가능성은 있으나 이 PNG만으로 이력, 원래 화면 해상도, 축소율, 브라우저 배율, OS 배율을 확정할 수 없다. 따라서 **579 × 349px는 비교용 기준 캔버스이지 당시 미니홈피의 실제 CSS 크기라는 뜻이 아니다.** 이후 더 선명한 자료가 확보되면 원래 구현 크기와 비교용 배율을 별도로 정해야 한다. 현재 단계에서 임의로 1.5배·2배 역산하지 않는다.

### 정렬과 간격

- HOME 본문의 공통 왼쪽 기준선은 x≈168이다. 패널 시작 x=150에서 약 18px 안쪽이다.
- 본문 오른쪽은 x≈408이다. 여기에서 스크롤바 시작 x≈417까지 약 9px이다.
- 제목은 x≈181에서 시작해 본문 기준선보다 약 13px 오른쪽에 있다. 제목과 본문을 일괄 왼쪽 정렬하지 않는다.
- 최근 게시물 오른쪽 목록은 대략 x=290과 x=350에서 두 열로 나뉜다. 첫 열 분리선은 x≈287, 가로 구분선은 y≈84, 98, 112, 126으로 읽힌다. 정확한 선 위치는 ±2px 추정이다.
- 미니룸은 240 × 75px로 약 3.20 : 1이다. 보기 링크 하단과 미니룸 상단이 거의 맞닿는다.
- 미니룸 아래 y=217에서 다음 제목 띠 y=222까지 약 5px 간격이 있다.
- 프로필 그림과 하단 HISTORY 사이에는 큰 빈 공간이 있다. 빈 공간도 배치의 일부다.
- 좌측 패널 모서리는 대략 5~7px 반경으로 보인다. 외곽 프레임은 대략 6~9px 정도지만 굴곡과 흐림 때문에 단일 반경으로 확정하지 않는다.

### 바인더와 탭

바인더는 두 고리씩 위·아래에 배치된 총 네 개다. 모두 x≈143..155에 걸쳐 양쪽 패널 경계를 덮으며 중심축은 x≈149이다. 위쪽 쌍의 시작 y는 105, 122이고 아래쪽 쌍은 250, 267이다. 쌍 안의 시작점 간격은 약 17px, 위·아래 대응 고리의 시작점 간격은 약 145px이다. 회색 윤곽과 밝은 내부가 보이는 납작한 고리이며 패널 위에 그려져 있다.

탭은 x≈432에서 시작해 프레임 오른쪽 x≈454를 넘어 x≈463까지 약 9px 돌출된다. 첫 탭만 밝은 바탕이고 나머지는 청록색 계열이다. 탭의 왼쪽 접합부, 프레임과의 겹침, 오른쪽 모서리의 작은 곡률을 별도 요소로 취급해야 한다.

## 색상과 선

아래 값은 지정한 사각형 안의 픽셀을 RGB 채널별로 중앙값 계산한 결과다. 픽셀 표본값은 재현 가능하지만 **원래 CSS 색상값을 복구한 것은 아니다.** 탭 표본에는 테두리·중간색도 일부 포함되어 단색 배경값으로 단정할 수 없다.

| 대상 | 표본 영역 (x, y, w, h) | 중앙값 |
| --- | --- | --- |
| 격자 배경 | 480, 220, 70, 100 | `#a3a3a3` |
| 하늘색 프레임 | 22, 55, 6, 235 | `#acd2dd` |
| 프로필 빈 바탕 | 45, 175, 90, 55 | `#ffffff` |
| 하단 회색 제목 띠 | 180, 225, 220, 5 | `#f5f5f5` |
| 비활성 탭 왼쪽 부분 | 435, 110, 6, 120 | `#2c8daf` |

격자는 가로·세로 약 9px 주기로 보인다. x=480..514, y=220..329의 열 평균 밝기에서 x=484, 493, 502, 511 부근이 어둡고, x=480..549, y=220..249의 행 평균에서는 y=228, 237, 246 부근이 어둡다. 이는 현재 이미지에서 관측한 주기이며 원래 배경 자산의 주기는 미확정이다.

패널 테두리·미니룸 테두리는 대략 1px의 회색 선으로 보이고 주변으로 중간색 픽셀이 퍼진다. 점선 둘레는 밝은 작은 대시가 이어진 형태다. 점선의 정확한 대시 길이·간격, 그림자 색상과 번짐, 텍스트 전경색은 이 단계에서 확정하지 않는다. 제목의 청록색, 상단 제목의 짙은 청색, 동작 링크의 주황색, 본문의 회색은 서로 구분되는 색 역할로 기록한다.

## 글자 계측의 한계

| 대상 | 이미지에서 보이는 글자 높이 추정 | 기타 관측 |
| --- | --- | --- |
| 상단 메뉴·카운터 | 약 5~7px | 매우 작은 글씨, 촘촘한 가로 배치 |
| 본문·탭·프로필 문구 | 약 6~8px | 본문은 회색, 비활성 탭은 밝은 글자 |
| 섹션 제목 | 약 7~9px | 청록색, 본문보다 굵게 보임 |
| 미니홈피 제목 | 약 9~10px | 짙은 청색, 굵게 보임 |
| 최근 게시물 목록 행 간격 | 약 14px | 글리프 높이가 아닌 행 위치 간격 |

이 수치는 글리프의 가시 높이 추정이지 CSS `font-size`나 `line-height`가 아니다. 정확한 폰트명, 굵기 수치, 렌더링 엔진, 글자 간격은 현재 이미지로 식별할 수 없다. 익숙한 옛 Windows 글꼴을 추정만으로 확정하거나, 작은 글씨를 현대 웹의 일반적인 크기로 확대하지 않는다.

## 다음 단계로 넘길 미확정 항목

1. 기준 화면과 같은 시기·테마인지 판별할 수 있는 더 선명한 실제 자료와 그 출처.
2. 캡처의 원래 배율과 당시 고정 레이아웃의 CSS 크기.
3. 글꼴과 한글 렌더링 방식, 흐려진 작은 문구 및 메뉴 표기의 정확한 판독.
4. 프레임 상하 굴곡, 바인더의 음영, 탭 접합부, 점선 패턴의 세부 형태.
5. 프로필 그림, 미니룸 캐릭터, 말풍선, 우측 배너의 원래 자산과 원본 크기.
6. 우측 부가 영역 내부의 세부 구획. 이번에는 외접 영역만 계측했으며 확대 자료 없이 작은 조작부를 확정하지 않았다.

현재 문서는 1차 관측 기록이다. 작업 2의 자료 조사 뒤 작업 3에서 구현 기준을 확정하며, master와 보조 자료가 충돌하면 master의 가시 배치를 우선한다.
