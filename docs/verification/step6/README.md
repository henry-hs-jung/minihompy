# 작업 6 시각 보정

Master를 기준으로 작업 5 화면과 보정 화면을 동일한 579 × 349, DPR 1에서 비교했다. Chromium 버전과 실제 폰트·영역 좌표는 [검사 결과](results.json)에 기록했다. 작업 4·5 캡처와 원본 이미지는 변경하지 않았다.

겹침·차이 그림은 검사용 브라우저 canvas에서 만든 진단 자료다. 실제 HOME에 원본 전체 이미지를 덮지 않는다.

## 적용한 보정

프레임 안쪽 보조선을 점선 안으로 옮기고 펼침면·격자의 색과 점선 대비를 조정했다. 하단 점선은 2px, 펼침면과 패널 하단은 1px 올렸다. 관측값은 유지하고 구현 보정값을 명세의 `geometryRefinements`에 분리했다.

최근게시물 제목 밑줄을 왼쪽 열까지만 표시하고 통계 두 열을 x=290,350으로 맞췄다. 빈 상태 안내를 2px 내리고 옅은 배경을 넣었다. 프로필 하단 선택 상자는 2px, 페이지 제목은 1px 내렸다. 우측 관계 위치, 검색어, 앱스·작은 숫자·음악 기호를 보완했다.

역할별 크기 후보는 [type-study.json](type-study.json), 위치 후보는 [position-study.json](position-study.json)에 기록했다. 본문을 일괄 확대하지 않고 상단·미니룸 보기·우측 보조 글자와 통계 라벨만 6.5px로 조정했다. 탭의 글꼴·자간·가로 배율은 변경하지 않았다. 말풍선의 0.5~1px 이동은 차이가 커져 적용하지 않았다.

## 차이 측정

0~255 RGB 채널의 평균 절대 차이(MAE)이며 낮을수록 픽셀 차이가 적다. 아래 영역은 위치를 고정해 변경 전후를 비교했다. 전체 값에는 빈 흰 공간과 동일 그림 네 곳도 포함되므로 '복원 정확도 %'로 해석하지 않는다.

| 영역 | 작업 5 | 작업 6 |
| --- | ---: | ---: |
| 전체 | 6.435 | 5.439 |
| 프레임 위 | 8.337 | 6.317 |
| 프레임 아래 | 11.430 | 6.525 |
| HOME 본문 | 11.631 | 8.646 |
| 프로필 하단 | 9.382 | 8.559 |
| 우측 | 16.488 | 14.732 |
| 일촌평 | 5.484 | 5.506 |
| 탭 | 19.458 | 19.458 |

전체 수치는 약 15.5% 감소했다. 일촌평 아이콘은 원본의 흰 중심을 재현했지만 해당 영역 MAE는 소폭 증가했다. 이를 숨기거나 전체 점수만으로 통과시키지 않았다. 전체 영역 수치는 [comparison.json](comparison.json)에 있다.

## 검증과 한계

세 viewport에서 14개 골격 영역이 초기 관측 허용치 안에 있으며, 보정 명세와의 차이는 1px 이내다. 미니룸·일촌평 띠·안내줄은 계측 좌표와 일치한다. 네 고리·아홉 탭·HOME 선택·빈 미니룸·두 배너·하단 빈 공간을 유지했다. 글자 영역 초과, 로컬 이미지·폰트 로딩 오류가 없고 모바일에서는 축소 없이 오른쪽 끝까지 이동된다. 캡처와 겹침을 육안 확인했다.

Galmuri는 원본 돋움/굴림의 확인된 복구본이 아니다. 작은 글자 획과 안티앨리어싱, 탭 가장자리, 말풍선의 곡선·꼬리, 작은 음악 아이콘에는 차이가 남는다. 원본 캡처의 압축 흔적·색 번짐을 맞추기 위해 화면 전체를 흐리게 처리하지 않았다. 시각 보정 단계를 마쳤다는 뜻이지 픽셀 단위 완전 일치를 주장하는 것은 아니다. 기능 개발과 7번 최종 검수는 수행하지 않았다.

## 재실행

```sh
node scripts/verify-home.mjs /path/to/playwright/index.mjs
node scripts/compare-home.mjs /path/to/playwright/index.mjs
```

글꼴 후보를 다시 조사하려면 `scripts/study-home-type.mjs`를 실행한다. 세 번째 인자 `positions`로 위치 후보를 비교한다. 현재 CSS에 후보를 적용하는 방식이므로 재실행한 후보 기록은 해당 시점의 CSS에 대한 기록이다.
