# 작업 5 검증

정적 HOME 내용 채우기 완료. 6번의 오버레이 정밀 보정은 아직 수행하지 않았다.

- [기준 크기 캡처](579x349.png)
- [데스크톱 캡처](1280x800.png)
- [모바일 왼쪽](375x812.png), [오른쪽 끝](375x812-right.png)
- [자동 검사 결과](results.json)

`scripts/verify-home.mjs`로 Chromium, DPR 1에서 세 viewport를 검사했다. 기존 14개 골격 영역의 오차 1px 이내, 아홉 탭과 HOME 선택 표시 유지, HOME 글자 영역 초과 없음, 네 그림의 위치·크기와 이미지 디코딩·유색 픽셀, 본문/탭 웹폰트 실제 사용, 로컬 리소스 오류 없음, 고정 캔버스와 모바일 가로 스크롤을 확인했다. 캡처를 열어 그림과 내용 배치도 육안 확인했다.

본문은 별도 Galmuri11 서브셋을 사용하고 탭의 가로 압축을 상속하지 않는다. 원본 폰트와 완전히 같은 획을 보장하지 않으며 제목 굵기, 작은 본문 획, 경계선·말풍선 윤곽의 세밀한 차이는 6번 비교 대상으로 남긴다. 기능은 모두 정적 표시다.
