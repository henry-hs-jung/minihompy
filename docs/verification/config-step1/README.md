# 구조 작업 1: Config 연결 검증

- [기본 화면](579x349.png), [설정 변경 예시](custom-config.png)
- [기본 화면·리소스 검사](results.json), [설정 동작 검사](config-results.json)

기존 HOME 검증을 579 × 349, 1280 × 800, 375 × 812의 Chromium DPR 1에서 재실행했다. 네 캡처(모바일 오른쪽 포함)의 파일 내용이 작업 7과 동일함을 자동 검사했다. 프레임·탭·고리·미니룸의 기본 디자인은 보존된다.

임시 로컬 파일 묶음에 변경한 Config를 실제로 기록하고 로딩하여 제목·소개·이름 두 위치·카운터·말풍선·일촌평·줄바꿈·빈 보조 문구를 확인했다. 새 한글이 확장 웹폰트를 로드하고 외부 요청 없이 표시됨을 검사했다. HTML 형태의 문구가 실행되지 않고 문자로 표시되며, 잘못된 타입은 기존 문구를 유지하는 것도 확인했다. 기본 화면과 변경 예시 캡처를 육안 확인했다.

메뉴의 순서·표시 여부를 변경해도 기존 아홉 탭을 유지하는 것이 현재 의도한 동작이다. 설정을 통한 탭 필터링과 화면 전환은 3번에서 연결한다. 긴 문구의 최종 처리 기준과 다른 브라우저·실제 모바일 기기 검증은 이번 완료 범위가 아니다.

```sh
node scripts/verify-home.mjs /path/to/playwright/index.mjs docs/verification/config-step1
node scripts/verify-config.mjs /path/to/playwright/index.mjs
```

두 번째 스크립트는 첫 번째가 생성한 기본 캡처를 비교하므로 위 순서로 실행한다. 실제 사용자 Config 파일은 변경하지 않고 임시 파일은 검사 후 제거한다.
