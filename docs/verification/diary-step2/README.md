# D10 다이어리 구현

2026-09-13. 사용자가 D10을 기준으로 채택하여 일기 읽기 화면을 구현했다. 외곽 프레임과 탭은 master를 유지한다. 작성·저장·로그인·Supabase는 구현하지 않았다.

## 화면 기준

- [D10](../../../references/diary/D10.jpg)의 왼쪽 위 다이어리: DIARY 제목, 작은 쓰기 표시, 폴더 목록, 하단 관리 영역.
- 본문 상단 240 × 34px 날짜 막대: 큰 청록색 월·일, 요일, 작은 연·월과 두 줄 날짜 목록. 왼쪽 월간 달력은 넣지 않았다.
- 본문은 청록색 날짜·시각, 작은 날씨 텍스트, 왼쪽 정렬 일기와 흰 여백, 가는 테두리로 구성했다. 사진첩의 회색 중앙 제목 띠를 사용하지 않는다.
- 본문 7px/11px, 시각 6px, 날짜 숫자 5px, 큰 월·일 13px. 자간 0. 기존 Galmuri 대체 폰트와 Arial을 사용하며 원본 서체 복구를 주장하지 않는다.
- 날짜 막대 아래 본문만 내부 스크롤. 스크롤바는 사진첩의 9px 스타일을 재사용하며 휠·터치·화살표·트랙·드래그·키보드 이동이 가능하다.
- 댓글은 승인된 사진첩의 클래스·색상·입력칸을 재사용했다. 일기와 사진·댓글 내용은 샘플이다.

## 구현 선택

D10 정지 이미지에서 의미가 확정되지 않은 부분은 다음처럼 정했다. 원본 동작을 확인한 사실과 구별한다.

- 큰 월·일은 선택 날짜. 선택일은 청록 배경, 글 있는 날짜는 짙은 글씨, 주말은 색으로 구분한다.
- 폴더를 바꾸면 그 폴더의 최신 일기 날짜로 이동한다. 빈 폴더는 현재 날짜를 유지한다.
- 날짜 선택 시 해당 날짜의 모든 글을 시각 순으로 표시한다. 월 이동 시 일자를 유지하되 없는 일자는 말일로 조정한다.
- 빈 날에는 `등록된 일기가 없습니다.`를 표시한다.
- 쓰기·관리·포도 수는 시각 표시뿐이다. 댓글 입력과 확인 버튼은 비활성이다.
- 메뉴 왕복 동안 날짜·폴더를 메모리에 유지하며 새로고침하면 초기 샘플 날짜로 돌아온다.

## 파일

- [diary-data.js](../../../diary-data.js): 초기 날짜, 폴더, 일기와 댓글 샘플. 날짜는 `YYYY-MM-DD`, 시각은 `HH:mm`. 공개 일기의 유효한 데이터 구조를 전제로 한다.
- [views/diary.js](../../../views/diary.js): 기존 좌측·본문 fragment 방식으로 등록. 모든 데이터 문구는 textContent로 처리한다.
- [styles.css](../../../styles.css): 다이어리 전용 클래스. 댓글·폴더 아이콘·스크롤바는 사진첩 스타일을 활용한다.

## 검증

`verify-diary.mjs` 통과: 1000 × 700 DPR 1, 375 × 812 DPR 1·2. 폴더·날짜·월 이동, 글 없는 날, 사진 첨부, 같은 날 복수 글, 댓글·스크롤, HOME/사진첩 왕복을 확인했다. 별도 579px 화면에서 긴 글·긴 폴더명과 2008년 윤년 2월을 검사했다. 브라우저 오류·요청 실패는 기본 세 조합에서 없었다.

`verify-navigation.mjs`의 15개 메뉴 시나리오 통과. HOME은 작업 7 기준 이미지와 동일했다. 사용자 Config와 사진첩 데이터는 수정하지 않았다. Safari·Firefox·실제 모바일 기기는 미검증이다.
