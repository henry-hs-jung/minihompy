# 작업 7 최종 검수

정적 HOME의 시각 복원 단계 검수를 완료했다. 제품 HTML/CSS/그림/폰트는 변경하지 않았으며, 검증 스크립트에 인접 글자 겹침·외부 요청·검색 비활성 검사를 추가했다. 로그인·게시판 기능이나 배포 작업은 수행하지 않았다.

Playwright Chromium, DPR 1에서 579 × 349, 1280 × 800, 375 × 812 viewport로 확인했다. 이는 데스크톱 Chromium의 작은 viewport 검사이며 실제 휴대전화 검증은 아니다.

| 검사 | 결과 |
| --- | --- |
| 14개 골격 영역과 프레임 | 초기 관측 허용치 및 보정 명세 범위 통과 |
| 아홉 탭·HOME 선택·네 고리 | 유지 |
| 미니룸·일촌평 위치와 빈 하단 | 계측 좌표 및 시각 확인 통과 |
| 프로필·미니미·배너 두 개 | 로딩·크기·위치·유색 픽셀 검사 통과 |
| 본문·탭 글꼴 | 번들 웹폰트 실제 사용 확인 |
| 작은 문구 넘침 | 검사 대상 영역 초과 없음 |
| 인접 문구 | 상단 메뉴·미니룸 보기·일촌평·통계·제목/우측 링크 겹침 없음 |
| 검색 | 입력과 버튼 모두 비활성 |
| 외부 요청·로컬 로딩 오류 | 외부 요청 없음, 오류 없음 |
| 고정 크기와 가로 이동 | 579 × 349 유지, 375px 폭에서 204px 이동 |

Master와 최종 캡처를 열어 구성 요소를 확인하고 데스크톱·모바일 좌우 캡처도 육안 확인했다. 네 캡처의 SHA-256이 각각 작업 6 캡처와 동일해 최종 검수 중 시각 변화가 없음을 확인했다.

## 인계 범위

[index.html](../../../index.html)을 직접 열어 사용한다. 실행 파일은 HTML·CSS·assets이며 서버·빌드·API 설정이 필요 없다. 자세한 실행 및 재검증 방법은 [README](../../../README.md)에 있다.

현재는 HOME 한 화면의 정적 복원이다. 탭 이동, 글 작성·댓글·방명록 저장, 로그인, 음악 재생, 실제 방문자 집계는 없다. Supabase와 GitHub Pages 배포도 미구현이다.

원본 폰트·CSS·개별 GIF의 복구를 주장하지 않는다. 대체 폰트의 획과 탭 윤곽, 말풍선·아이콘에 차이가 남으며, 원본 화면 자체의 압축·축소 흔적도 있다. 공개 배포 전 그림 사용 권리 확인이 필요하다. 실제 기기·다른 브라우저·다른 DPR에서의 동일 렌더링은 보장하지 않는다. 기능 확장은 이 시각 복원 단계와 분리해 진행할 작업이다.
