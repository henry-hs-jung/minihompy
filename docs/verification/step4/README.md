# 작업 4 검증 기록

정적 HOME 골격을 구현했다. [화면 열기](../../../index.html) · [HTML](../../../index.html) · [CSS](../../../styles.css)

## 구현 범위

579 × 349px 캔버스, 상단 메뉴와 비활성 검색 필드, 9px 격자 배경, 중앙 굴곡을 포함한 하늘색 프레임·점선·펼침면, 두 흰 패널, 고리 네 개, 오른쪽 탭 아홉 개, HOME 스크롤바 모양, 우측 부가 영역의 구획과 작은 조작부를 구현했다.

프로필 그림·카운터·미니홈피 제목·HOME 본문·미니룸·배너는 작업 5 대상으로 남겨 두었다. 빈 패널은 누락이 아니라 현재 단계의 범위다. 탭은 정적 메뉴 표기이며 검색·음악·게시 기능은 동작하지 않는다. 앱에 실행용 JS나 외부 의존성이 필요하지 않아 이번 단계에는 추가하지 않았다.

Chromium 151.0.7922.34, DPR 1, 로컬 `file:` URL로 검증했다. 실행 결과는 [results.json](results.json)에 있다.

## 남은 차이

탭 보정 후 재검증과 스크린샷을 갱신했다. 현재 탭은 로컬 `Galmuri11` 서브셋을 사용하며 이전 `WenQuanYi Zen Hei` fallback에서 변경되었다. 원본 폰트로 확인된 것은 아니다. 프레임·고리의 가는 음영, 점선, 잠정 색상은 이후 콘텐츠와 함께 비교 보정한다. 좌표 일치는 각 요소의 외접 영역 기준이며 고리 내부 윤곽의 픽셀 일치까지 의미하지 않는다.

검증 스크립트는 [verify-skeleton.mjs](../../../scripts/verify-skeleton.mjs)다. DevTools에서 폰트를 조사할 때 발생하는 별도 file URL 재조회는 앱의 초기 로드 검증과 분리했다.
