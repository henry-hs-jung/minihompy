# 전체 1.5배 표시

2026-09-14: 900×560px 이상 창에서 원본 레이아웃을 양축 1.5배로 표시한다. 작은 창은 1배로 유지한다.

확인 항목: 정확한 868.5×523.5px 표시, 내부 579×349px 유지, 창 크기 변경 시 배율 전환, 로그인 창 동일 배율, 긴 이름 말줄임, 확대 좌표 기준 스크롤바 드래그. 기존 HOME 1배 픽셀 기준도 유지한다.

통합 실행의 사진첩 검사 한 곳은 확대된 화면 좌표와 확대 전 clientWidth를 혼용해 실패했다. `verify-photos-writing.mjs`에서 양쪽을 내부 좌표로 맞춘 뒤 단독 재실행하여 데스크톱/모바일 모두 통과했다. `release/results.json`에는 최초 통합 실행의 해당 실패가 남아 있다. 다른 검사 결과와 이 재검증을 함께 해석한다.

`verify-scale.mjs`의 경계값/로그인 창 검사는 별도로도 통과했다. 캡처 PNG는 Git에서 제외하고 로컬에 보관한다.
