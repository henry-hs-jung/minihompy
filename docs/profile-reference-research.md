# 프로필 자료 조사

조사일: 2026-09-13. **부분 조사 결과이며, 모든 하위 메뉴 복원에 충분한 자료를 확보한 상태는 아니다.** 앱 코드 변경 없음.

후속 작업: 사용자가 미확인 본문을 빈칸으로 두는 구현을 승인했다. [정적 구현 기록](profile-implementation.md)을 참고한다. 아래는 조사 당시 확인 수준을 그대로 보존한 기록이다.

## 기준과 결과

사용자 지정 [PR01 원본](https://img.tf.co.kr/article/home/2014/12/06/20142061417847722.jpg)을 프로필 내부 기본틀의 SoT로 고정한다. 기존 `cyworld-master.png`는 전체 캔버스·외곽 프레임·바인더·우측 탭의 기준으로 유지한다. 프로필을 소개하는 기사 사진이라고 해서 HOME의 프로필 영역과 혼동하지 않는다.

[로컬 원본](../references/profile/PR01-sot.jpg) · [자료 확인 페이지](../references/profile/index.html) · [해시·출처](../references/profile/manifest.json)

SoT는 [더팩트 기사의 네이트 재송고 페이지](https://news.nate.com/view/20141206n09848)에 수록되어 있다. 기사 게시 시점은 2014-12-06이다. 사진 속 날짜 2004-03-16은 사진에 인쇄된 날짜로 UI 촬영일이 아니다. 이 자료만으로 2004년 UI 또는 2014년 신규 UI라고 확정하지 않는다.

## SoT에서 직접 확인한 구조

왼쪽은 `Profile` 제목과 청록색 가로선, 펼쳐진 `내 소개`, 접힌 `내 인맥`, 접힌 `내 즐겨찾기`로 구성된다. 내 소개의 하위 순서는 다음과 같다.

1. 소개
2. 키워드
3. 히스토리
4. 42문답
5. 기본정보

선택된 소개는 청록색 굵은 글씨, 나머지 하위 항목은 회색이다. 상위 묶음은 청회색 굵은 글씨와 작은 회색 아이콘, 우측 펼침 표시를 사용한다. 상위 묶음 사이에 매우 옅은 선이 있다. 현재 화면에서 회색이라는 이유만으로 하위 메뉴를 비활성 기능이라고 단정하지 않는다.

오른쪽은 사진 뒤에 이름과 자유 서술 문단이 이어지는 흰 본문이다. 별도의 카드, 큰 제목, 항목별 표, 연대표는 보이지 않는다. 이력처럼 보이는 문장도 **선택된 메뉴가 소개이므로 히스토리 화면의 증거가 아니다.** 사진 폭과 본문 가용 폭은 다르며 사진을 본문 전체 너비로 강제하지 않는다.

### 원본 계측

680×452 이미지 기준 육안 계측. JPEG 경계 오차 약 1~3px. 원 서비스 CSS의 원래 px 값은 아니다.

| 요소 | 대략적인 위치·크기 |
| --- | --- |
| 좌측 흰 패널 | x24, y56, 폭171, 높이367 |
| 우측 흰 패널 | x199, y56, 폭435, 높이367 |
| Profile 제목 | x47, y77 |
| 청록 가로선 | x40~178, y94 |
| 상위 메뉴 글씨 시작 | x64, 내 소개 y104 부근 |
| 하위 메뉴 글씨 시작 | x65, 소개 y123 부근 |
| 하위 메뉴 줄 간격 | 약14px |
| 묶음 경계 | y192, y219, y246 부근 |
| 본문 사진 | x229, y87, 폭294, 높이221 |
| 사진 아래 이름 | x229, y310 부근 |
| 본문 왼쪽 여백 | 패널 기준 약30px |
| 스크롤 레일 | x611~622, y65~409 |

기존 패널 높이 240px에 맞춰 단순 비교하면 축척 약0.654. 하위 메뉴 줄 간격 약9px, 본문 왼쪽 여백 약20px, 사진 약192×145px가 초기 비교값이다. 좌우 패널을 각각 현재 크기에 맞춰야 하므로 원본 전체를 일괄 축소하는 구현은 피한다. 폰트명은 미확정이며 기존 탭의 가로 압축값을 본문에 자동 적용하지 않는다.

## 하위 메뉴별 근거

| 메뉴 | 무엇을 확인했는가 | 아직 모르는 것 | 구현 판단 |
| --- | --- | --- | --- |
| 소개 | SoT에서 사진과 자유 서술 문단을 직접 확인 | 편집기 상세, 복수 소개 글 여부, 하단 컨트롤 | SoT 범위의 정적 화면 가능 |
| 키워드 | SoT에 메뉴 존재 | 직접 입력인지 검색 기록인지, 항목·개수·정렬·색상·링크 동작 | 본문 구현 보류 |
| 히스토리 | SoT에 메뉴 존재 | 대문 변경 이력인지 개인 연혁인지, 사진/날짜/문장 배치 | 본문 구현 보류 |
| 42문답 | SoT에 메뉴 존재 | 고정 질문 여부, 질문 수·문구, 작성·열람 형태, 공개 범위 | 일반 백문백답을 대입하지 않음 |
| 기본정보 | SoT 메뉴와 당시 정보 항목을 정리한 간접 자료 | 실제 표/목록 모양, 필드 순서, 공개설정 표시, 필수/선택 구분 | 필드 후보만 기록, 화면 spec 미확정 |
| 내 인맥 | SoT의 접힌 상위 묶음 | 일촌·클럽 등의 정확한 하위 구성, 목록 열, 페이지 처리 | 접힌 외형만 근거 있음 |
| 내 즐겨찾기 | SoT의 접힌 상위 묶음 | 하위 메뉴, 즐겨찾은 대상 종류, 썸네일·텍스트 배열 | 접힌 외형만 근거 있음 |

### 기본정보: 간접 자료

[Xarsrima의 서비스 캐릭터 미니홈피 조사](https://xarsrima.tistory.com/1066)는 가입일·생일·혈액형·이메일·주소·성별 등을 기록하고 일부 값은 비공개라고 적었다. 이는 정보 항목의 존재를 뒷받침하지만, 글쓴이가 여러 위치에서 모아 정리했을 수 있으므로 **모두 기본정보 화면의 필드였다고 확정할 수 없다.** 사용자 연락처를 샘플로 복사하지 않는다.

[2010년 이미지 크기 사용기](https://xarsrima.tistory.com/1017)는 미니홈피 프로필 이미지 가로 크기를 400px로 정리했다. HOME 대문사진·C로그의 프로필 이미지 크기와 구분한다. 이는 업로드 이미지의 크기 설명이지 본 프로젝트의 표시 폭 지시가 아니다.

### 키워드: 혼동 방지

[2004년 SK커뮤니케이션즈 검색 서비스 보도자료](https://www.newswire.co.kr/newsRead.php?no=22377)는 검색어를 일촌과 공유하는 기능을 설명한다. 하지만 이 기능이 SoT의 프로필 > 키워드 메뉴에 표시되었다는 연결 근거는 찾지 못했다. 취향 태그 목록이나 검색 기록 목록 중 하나로 임의 확정하지 않는다.

### 히스토리: 같은 이름의 다른 기능

[2008년 마이싸이월드 사용기](https://xarsrima.tistory.com/488)의 히스토리는 일촌보기의 관계 기록이며, 서로 남긴 댓글·일촌평·일촌명 변화를 다룬다. 이 글의 기본정보도 마이싸이월드 내정보 영역이다. 둘 다 SoT의 내 소개 하위 화면과 동일하다고 볼 수 없다.

[2013년 투데이 히스토리 설명](https://zdnet.co.kr/view/?no=20130323171927)은 과거 같은 날짜의 게시물을 되돌아보는 기능이다. 이것 역시 프로필 > 히스토리 화면을 설명하는 증거로 사용하지 않는다. HOME의 EDIT/HISTORY를 눌렀을 때 어디로 연결되는지도 현재는 확인하지 못했다.

### 42문답: 질문 목록 미확정

[2007년 문답 게시물](https://pann.nate.com/talk/116919528), [2008년 프로필 문답 양식](https://pann.nate.com/talk/118944467)은 당시 문답을 복사해 사용한 문화의 자료다. 그러나 프로필의 42문답 메뉴와 연결되는 캡처나 공식 설명이 없다. 숫자 42를 보고 정확히 42개의 고정 질문이 있었다고 단정하거나, 검색된 백문백답에서 42개를 골라 원본이라고 제시하지 않는다.

## 조사 경로와 제외 사유

- 한국어 메뉴명 그대로, 띄어쓰기 변형, 싸이문답/사이문답, 영문 Cyworld profile tutorial/keyword/history/questions로 검색했다. 텍스트 검색과 이미지 검색을 모두 사용했다.
- 당시 사용기 Xarsrima의 프로필 검색 3페이지, 키워드 검색, 관련 이미지 크기 글과 서비스 캐릭터 정보 글을 확인했다. 내정보·마이싸이월드·C로그를 분리했다.
- [Korean Wiki Project 안내](https://www.koreanwikiproject.com/wiki/Cyworld)는 프로필 아래 참여 클럽이라는 항목을 언급하지만 세부 UI가 없고 페이지가 미완성이라고 명시한다. 내 인맥의 정확한 하위 메뉴를 복원하기에는 부족하다.
- [KoreanClass101 포럼](https://www.koreanclass101.com/forum/viewtopic.php?t=2035)은 Profile/소개를 Diary라고 혼동한 설명이 있어 메뉴 증거로 채택하지 않았다.
- [2005년 입문서의 공개 목차](https://m.yes24.com/goods/detail/1480203)는 확인했지만 하위 메뉴 본문이나 상세 페이지를 확보하지 못했다. 책을 읽었다거나 메뉴를 확인했다고 주장하지 않는다.
- D10/G01을 제공한 발표 자료의 설명문도 확인했으나 요청한 프로필 하위 화면의 근거는 찾지 못했다.
- [파란펭귄 프로필 검색 결과](https://paranpenguin.co.kr/?act=dispBoardContent&document_srl=194556&mid=PPT)의 실제 이미지는 HOME형 PPT 템플릿이다. 프로필 하위 화면이 아니므로 제외했다.
- 최근 재출시 모바일, C로그, 타 SNS 프로필, 생성형 해설·복원 템플릿은 초기 PC 프로필의 기하 근거로 쓰지 않았다. 이미지 검색의 자동 설명도 원본을 대신하지 않는다.

## 다음 판단

현재 확실히 복원할 수 있는 범위는 **좌측 메뉴 기본틀과 소개 화면**이다. 나머지 하위 화면은 추가 원본이나 당시 설명서 페이지가 필요하다. 추가 자료가 없는 상태에서 구현을 진행한다면, 원본 복원과 추정 설계를 명확히 분리해서 사용자와 범위를 먼저 정해야 한다. 이번에는 미확인 하위 메뉴를 임의 구현하지 않았다.
