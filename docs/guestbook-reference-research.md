# 방명록 시각 자료 조사

조사일: 2026-09-13. 조사 후 사용자가 G01을 구현 기준으로 확정했다. G02는 같은 구조의 공개글 보조 자료로 사용한다. 정적 구현 결과는 [구현·검증 기록](guestbook-implementation.md)을 참고한다.

## 결론

**확정 기준은 G01**이다. 다이어리 D10과 같은 발표 자료의 26번 슬라이드이며, 기존 파란 프레임과 유사한 미니홈피에서 작성 영역·공개글·댓글·비밀글을 함께 볼 수 있다. 단, 글 날짜가 2009년이므로 사용자가 처음 요청한 2008년 이전 시기의 증거는 아니다.

G02는 2005년 글이 보이는 한국어 방명록의 배치·글씨 비교용이다. G03은 2008년 당시에 출판된 논문 속 화면으로, 미니미와 글·응답의 구조를 교차 확인하는 자료다. **어느 것도 master 전체 프레임을 대체하지 않는다.**

## 실제로 보이는 구조

### 좌측

- G01과 G02 모두 사진첩·다이어리의 폴더 탐색기가 아니라 프로필 사진, 소개, 이력, 이름 등이 있는 영역이다.
- 따라서 복원 후보는 HOME 계열 좌측 영역 재사용이다. 자료마다 다른 상태표시·하단 버튼을 무작정 합치지는 않는다.

### 작성 영역과 공개글

- G01 왼쪽 위 캡처: 미니미 미리보기는 왼쪽, 큰 흰색 입력면은 오른쪽. 그 아래 작은 선택·확인 컨트롤이 붙는다. 확대해도 일부 문구는 확정하기 어렵다.
- 글의 맨 위에는 얇은 선과 매우 연한 회색 띠가 있다. 번호, 이름, 작은 집 아이콘, 괄호 안 날짜가 한 줄에 놓인다.
- 그 아래는 왼쪽 미니미/배경 이미지와 오른쪽 본문으로 나뉜다. 제목이나 현대적인 아바타 원형 배지는 없다.
- 댓글은 미니미 옆의 좁은 본문 열에 갇히지 않고 아래쪽으로 이어진다. G01·G02는 연한 회색 면, 작은 이름·본문·날짜를 확인할 수 있다.
- G01 오른쪽 아래 캡처에서는 댓글 입력줄과 작은 확인 버튼이 보인다. 글쓰기 입력면과 댓글 입력줄은 크기와 배치가 다르다.

### 비밀글과 관리 상태

- G01 오른쪽 아래에는 옅은 노란색 머리줄과 자물쇠 안내가 있는 글이 보인다. 원문이 보이는 권한 있는 열람 상태다.
- G01 공개글 오른쪽에는 비밀로 하기·삭제·신고 계열 작은 링크, G03에는 수정·삭제가 보인다. 각 캡처의 로그인 주체와 권한 전체를 확정할 수 없으므로 모든 방문자에게 동일하게 표시한다고 가정하지 않는다.
- 접근 권한이 없는 방문자의 비밀글 표현은 확보하지 못했다. 임의의 잠금 카드나 접힌 글 디자인을 발명하지 않는다.
- 비밀방명록 자체는 2005년 SK커뮤니케이션즈 보도자료에서도 확인된다. 이는 기능 존재의 근거이지, 노란색 UI가 그때도 동일했다는 증거는 아니다.

## 크기·폰트 판단

- G02의 원본 이미지에서 글 머리줄은 대략 x219~534, y149~168이다. 첫 글의 미니미 열은 x227~299, 본문 시작은 x307 부근이다. 육안 계측 오차 약 2~3px이며 CSS 원래 크기가 아니다.
- 따라서 글 폭 대비 미니미 열은 대략 23%, 본문 시작은 왼쪽에서 약 28% 지점이다. 기존 본문 폭 240px에 대응시키면 각각 약 55px, 67px지만 **확정 spec이 아닌 초기 비교값**이다.
- 작은 한국어 본문과 더 작은 날짜·번호의 위계가 중요하다. 스크린샷 압축·축소가 있어 정확한 폰트명, 원래 pt/px, 자간은 확정하지 못했다.
- 현재 폰트나 탭의 가로 압축값을 방명록 전체에 일괄 적용하지 않는다. 구현 단계에서 같은 한국어 문구를 넣고 실제 크기로 비교할 필요가 있다.
- 색상은 공개글의 연한 회색, 비밀글의 연한 노랑이라는 역할만 현재 확인한다. JPEG 샘플값을 원래 CSS 색상이라고 단정하지 않는다.

## 다음 구현에 앞서

1. G01을 기본으로 사용할지 선택한다. 선택되면 작성 영역·공개글·댓글을 먼저 구현하고, 비밀글은 별도 시각 상태로 검토한다.
2. 외곽 프레임·바인더·탭·고정 크기는 master를 유지한다. 미니미 자료는 연구 이미지에서 인물별 자산을 그대로 떼어 배포하지 않는다.
3. 이번 자료에는 방명록 하단 페이지 번호, 비회원 작성 폼, 빈 목록, 권한 없는 비밀글이 충분히 보이지 않는다. 페이지당 글 수와 해당 상태의 정확한 디자인은 미확정으로 남긴다.
4. 작성·저장은 다른 메뉴와 함께 나중에 개발한다. 이번 조사에서 기능 범위를 추가로 확정하지 않는다.
